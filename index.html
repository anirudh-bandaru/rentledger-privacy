RentLedger Privacy Policy

Effective date: 12 November 2026

1. About RentLedger

RentLedger is an offline rent ledger for a landlord’s own phone. It is used to keep properties, units, tenants, tenancies, rent, outstanding dues, payments, and payment history. Version 1.0.0 does not ask you to create a RentLedger account, and it does not provide RentLedger-operated cloud synchronization.

This page describes that Android release. It is the public privacy policy for the app package app.rentledger.

2. Information stored in RentLedger

The landlord enters the records the app keeps, which can include:

  • property names and addresses
  • unit labels
  • tenant names
  • tenant phone numbers, and optional email, alternate phone, emergency contact, and notes
  • tenancy dates, rent, maintenance, other charges, security deposit, and any stored rent increase
  • an opening outstanding amount, when the landlord chooses to enter one
  • payment amounts, dates, methods, references, and notes
  • an optional reminder preference, including a chosen channel and timing

This release does not ask for Aadhaar, PAN, identity documents, photographs, or file uploads.

3. How information is used

RentLedger uses these records on the phone to show what is due, record payments, and keep the history of a tenancy. A reminder preference is saved with the tenancy. The current release does not send WhatsApp or SMS messages.

RentLedger does not contain advertising. The shipping app does not include a third-party analytics or crash-reporting product. It does not take rent through a payment gateway. You enter each payment yourself.

4. Device contacts

Adding a tenant can start with Select from contacts or with Enter manually. Manual entry does not need contact permission.

If you choose Select from contacts, Android asks for permission to read contacts. RentLedger then copies the selected contact’s name, one phone number, and email, where those values exist, into the tenant form. You can edit every field before saving. The app does not upload your address book to a RentLedger service. It is not intended to change or delete contacts on the phone. If you deny contact access, you can still type the tenant.

5. Local storage

The ledger is stored in a database file in the app’s private storage on the phone. RentLedger does not encrypt that file itself. Android’s app sandbox keeps the app’s private files separate from other apps. That separation is not the same as encryption added by RentLedger.

Android backup of this app’s data is turned off. RentLedger does not copy the ledger into cloud backup or a backup-based phone transfer.

6. Network and sharing

RentLedger does not sell information. It does not send the ledger to a RentLedger server.

The Android install declares Internet access because the tools used to build the app include that permission. The current release does not use it to synchronize properties, tenants, rent, or payments. This public privacy page is hosted separately. Opening it in a browser loads this page only. That request does not include your ledger.

7. Data retention and deletion

You can correct records inside the app. A property, unit, tenant, or tenancy entered by mistake can be removed when it has no rent charge and no payment. If a stay has rent or a payment, the app keeps that history so the ledger stays consistent. You can archive a property, unit, or tenant to hide it from the active lists. Archive keeps the history.

A mistaken payment can be voided. The payment stays in the history and is left out of the totals. An unpaid rent charge can be cancelled and stays in the history. These actions do not erase the financial record.

There is no RentLedger account and no cloud copy to delete. Uninstalling the app removes its private data, including the ledger, under ordinary Android behavior. Installing it again does not restore those records. This release does not provide cloud recovery.

8. Security

RentLedger relies on the phone’s app sandbox to keep the ledger private to the app. It does not add application-level encryption to the database, and it does not provide end-to-end or cloud encryption of the ledger. Keep the phone’s own lock and accounts secure.

9. Children

RentLedger is a utility for a landlord managing rent. It is not directed to children and is not offered as a children’s service.

10. Changes to this privacy policy

If this policy changes, this page will be updated and the effective date at the top will change. The app has no account through which to send a notice.
